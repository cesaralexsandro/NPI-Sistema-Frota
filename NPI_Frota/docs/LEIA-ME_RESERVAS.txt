NPI FROTA — MÓDULO DE RESERVAS

A tabela public.reservas é utilizada pelo módulo de Operações > Reservas.

Campos esperados: id, solicitante, motorista_id, veiculo_id, categoria_veiculo, data_hora_retirada, data_hora_devolucao_prevista, destino, finalidade, centro_custo_id, projeto_id (legado), situacao, observacoes, aprovado_por, aprovado_em e created_at.

Para habilitar o acesso, execute sql/NPI_Frota_reservas_aprovacao.sql no SQL Editor depois do SQL principal de perfis e permissões. O script aplica RLS e cria a RPC npi_decide_reservation. Não remove registros.

Aprovações e recusas são feitas pelo botão de decisão na lista, para usuários com a permissão reservas.aprovar. A aprovação grava o usuário autenticado e o horário, e impede sobreposição com outra reserva aprovada para o mesmo veículo.

Atenção: esta implementação não substitui testes de RLS no projeto Supabase real. Verifique também as permissões do perfil Financeiro/Gestor na matriz de acessos.
