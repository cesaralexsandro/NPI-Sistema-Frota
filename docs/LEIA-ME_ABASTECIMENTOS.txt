NPI FROTA — ETAPA 5: ABASTECIMENTOS

O QUE FOI INTEGRADO
- O módulo Abastecimentos agora consulta e grava a tabela public.abastecimentos no Supabase.
- Campos relacionados a Veículo, Motorista, Centro de Custo e Projeto usam os cadastros já existentes.
- O Valor Total é calculado automaticamente por Quantidade de litros × Valor por litro.
- O indicador Abastecimento completo? é armazenado como booleano no PostgreSQL.
- A tabela possui políticas RLS para restringir o acesso à empresa do usuário e às permissões do perfil.

INSTALAÇÃO
1. Faça uma cópia de segurança da pasta da versão atual do NPI FROTA.
2. Execute o arquivo ../sql/NPI_Frota_abastecimentos.sql no SQL Editor do Supabase.
3. Extraia este ZIP e abra a pasta NPI_Frota no VS Code.
4. Inicie o index.html com Live Server.
5. Entre com um usuário que tenha permissão de visualizar/incluir Abastecimentos.

- Quantidade de litros: 30

OBSERVAÇÕES
- O exemplo é fictício; não representa um abastecimento real.
- Não execute este registro se o veículo tiver uma quilometragem atual superior a 45.025 km. Use a quilometragem atual real do cadastro.
- O consumo médio km/L exige histórico de abastecimentos e análise entre abastecimentos completos. O módulo atual grava os dados do abastecimento, mas não calcula um consumo confiável com apenas um lançamento.
- A configuração de RLS não concede acesso a usuários anônimos.
