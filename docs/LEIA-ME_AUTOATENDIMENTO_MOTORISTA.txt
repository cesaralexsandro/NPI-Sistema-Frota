NPI FROTA — AUTOATENDIMENTO DO MOTORISTA

O QUE MUDA
- O motorista vê uma lista de veículos disponíveis da própria empresa, sem precisar de atribuição prévia do administrador.
- Ao escolher um veículo, informa o serviço que vai realizar.
- O Supabase cria o vínculo, registra o serviço e reserva o veículo.
- Depois disso, o motorista pode iniciar a utilização preenchendo o checklist de saída.
- Após a devolução, o vínculo continua ativo até o motorista se desvincular, ou até um administrador/gestor encerrar o vínculo.
- Veículos em uso, manutenção, inativos ou já vinculados a outro motorista não aparecem como disponíveis.

INSTALAÇÃO
1. Faça uma cópia da pasta atual do NPI FROTA.
2. No Supabase, abra SQL Editor > New Query.
3. Abra ../sql/NPI_Frota_autoatendimento_motorista.sql, copie todo o conteúdo e execute.
4. Extraia este ZIP e substitua a pasta do site pela pasta NPI_Frota deste pacote.
5. Abra index.html pelo VS Code com Live Server.
6. Entre com um usuário do perfil Motorista e abra Meu Painel.

COMPORTAMENTO
- A lista de veículos disponíveis é fornecida por uma função RPC segura, limitada à empresa do motorista e apenas aos campos necessários.
- A vinculação é realizada por uma função SECURITY DEFINER que valida o usuário, empresa, situação do veículo e ausência de outro vínculo ativo.
- O veículo muda para Reservado ao ser autoatribuído.
- Ao iniciar a retirada, passa para Em utilização. Ao devolver, volta para Disponível.
- O serviço escolhido é guardado no vínculo e copiado para a retirada, preservando o histórico.
- O motorista pode se desvincular após devolver o veículo. O histórico não é apagado.

OPÇÕES DE SERVIÇO
Atendimento / visita técnica; Transporte de pessoas; Transporte de equipamentos; Entrega / retirada; Apoio operacional; Manutenção externa; Serviço administrativo; Outro.

Observação: a instalação SQL deve ser executada antes de testar os novos botões. Não compartilhe a chave secreta do Supabase.
