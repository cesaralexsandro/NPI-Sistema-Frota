NPI FROTA — HORÁRIOS NO HISTÓRICO DE UTILIZAÇÕES
================================================

A lista de Utilizações agora apresenta as colunas:
- Data/hora de saída
- Data/hora de retorno

Os valores são lidos dos campos existentes em public.utilizacoes:
- data_saida (timestamptz)
- data_retorno (timestamptz)

Esses campos são sincronizados pelo banco a partir de:
- retiradas.data_hora_retirada
- devolucoes.data_hora_devolucao

A interface formata o timestamp no fuso local do navegador em DD/MM/AAAA HH:MM.
Não é necessária migração SQL para esta alteração, pois os campos já existem como timestamptz.

Para atualizar, substitua a pasta do projeto pela pasta NPI_Frota deste pacote e abra
index.html usando Live Server. Nenhum registro existente é alterado.
